# Differential tests

`scripts/cowork_insights.py` and `scripts/cowork_insights.ps1` must stay
behaviorally identical — their three output files are byte-identical by
contract. After changing either implementation, re-verify:

```powershell
# 1. synthetic fixtures (covers discriminator, tie-breaks, BOM, bad bytes,
#    bad JSON, emoji clipping, subagent attribution, junction descent,
#    260+-char extended-length paths)
python tests\gen_fixtures.py $env:TEMP\ci-fix

# 2. run BOTH implementations against the fixture tree
$env:CLAUDE_CONFIG_DIR = "$env:TEMP\ci-fix\cfg"
$env:LOCALAPPDATA     = "$env:TEMP\ci-fix\la"
$env:APPDATA          = "$env:TEMP\ci-fix\ap"
python skills\cowork-insights\scripts\cowork_insights.py $env:TEMP\ci-py --days all
powershell -NoProfile -ExecutionPolicy Bypass `
  -File skills\cowork-insights\scripts\cowork_insights.ps1 $env:TEMP\ci-ps -Days all

# 3. byte-compare the three report files (exit 0 = identical)
python tests\compare_outputs.py $env:TEMP\ci-py $env:TEMP\ci-ps

# 4. confidence-split invariant: confirmed + ambiguous token totals must
#    equal token_grand_total exactly (exit 0 = reconciles)
python tests\check_split.py $env:TEMP\ci-py\cowork_full.json
```

Also run once against real data (unset the env overrides) — with the same
`--days all` window the outputs must again be byte-identical; for a
`--days 30` run pass `--normalize-cutoff` to compare_outputs.py, because
the runtime cutoff timestamp differs by a few seconds between the two runs.

Optional extras exercised during development, worth repeating after larger
changes: a junction inside the projects tree pointing at an external slug
dir (both implementations must descend and count it), a read-only source
file combined with `--stage`/`-Stage` (staging must succeed and preserve
the read-only flag while refreshing mtime), and `tests/gen_fixtures.py`'s
BOM / invalid-UTF-8 files (already generated by step 1).
